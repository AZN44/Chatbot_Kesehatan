# 🏥 Proyek Chatbot Kesehatan

Chatbot Python sederhana untuk informasi kesehatan dasar dan cek gejala ringan.

## ✨ Fitur
- Tanya jawab seputar info penyakit.
- Tips pola hidup sehat.
- Cek gejala kesehatan awal.
